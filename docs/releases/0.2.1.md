# v2025-0.2.1

减少杜比 PC 与 320Hz 切换中重复的黑屏步骤，并修正输入状态误判。

## 改进

- 320Hz 直接切换档位，按实际回读决定是否需要修正 HDR 或刷新率。
- 杜比 PC 配置使用 HDMI 能力刷新，省去额外的目标屏 PnP 重枚举、无条件 SDR 中转及重复分辨率设置。
- 停用 PC 覆盖后，HDR10 或 Dolby Vision 跟随 Windows 的杜比选择。原生档位保存了杜比偏好时，不再误报覆盖切换失败。
- 使用原生输入时序、杜比标志和丢信号查询确认结果，避免调试属性滞后造成误判。
- 点击后立即显示待应用状态与切换阶段；失败恢复也显示进度。
- 修正中文 Windows 下 ADB 输出的编码处理。

## 适用范围

Windows 11、红米 G Pro 27U 2025、`OS3.0.109.0.UFFMAMN` 固件、HDMI、FreeSync 开启。

工具箱保持点击前的 Windows HDR 开关状态，杜比类型跟随 Windows 在当前档位的选择。显示器仍需要完成 HDMI 重新连接；本次减少重复操作，不承诺所有状态都只黑屏一次。

安装版和便携版共用原有配置目录，可直接更新。
