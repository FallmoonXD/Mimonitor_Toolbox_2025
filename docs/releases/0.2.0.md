# Mimonitor Toolbox 2025 v0.2.0

## 杜比视界 PC 与 320Hz

- 游戏页新增“杜比视界 PC”的“开”“关”和“恢复原配置”。仅操作选中的 2025 款实体屏，保留原 EDID 配置供恢复。
- 开启兼容配置后，Dolby Vision 与实际 1080p 320Hz 可同时生效，普通档位也可使用 4K 160Hz Dolby Vision。
- 竞技模式自动选择 Windows 分辨率；处理开启 HDR 后自动回落 120Hz 的情况，回读实际输出时序及显示器原生输入后才确认成功。关闭时恢复进入前的分辨率。
- 等待 HDMI 路径重新出现、分辨率可用及输入稳定；失败时恢复切换前配置，并设有显示器端恢复机制。

需要 Windows 已有杜比支持，并在 Windows HDR 设置中启用杜比模式。本版兼容配置限定于 `OS3.0.109.0.UFFMAMN`、HDMI 和 FreeSync 开启的组合，切换需要管理员权限。不包含系统杜比组件安装。

## 调节响应优化与修复

- 复用显示器端控制进程，减少每次调节的进程启动与固定读取等待。普通滑块实测完成耗时中位数约 329 毫秒，色温约 355 毫秒；模式切换仍需等待信号稳定。
- 滑块提交间隔缩短到 120 毫秒；连续操作合并尚未执行的旧值，旧回执不会覆盖更新后的界面。
- 校色回读、场景检查、失败回退继续保留；通讯结果不明时不自动重复写入。
- 修正色温数据库枚举，以及 FreeSync 和 HDMI 竞技模式档位、专用通知的对应关系。

## 下载与升级

- `MonitorToolbox2025-Setup.exe`：Windows 64 位安装版，可直接升级现有 2025 版。
- `MonitorToolbox2025-portable.zip`：解压后运行 `MonitorToolbox2025.exe`。
- `SHA256SUMS.txt`：发布附件的 SHA256 校验值。

配置目录仍为 `%LOCALAPPDATA%\.gpro_controller_2025`，保留已有预设和设置。

## 验收

550 项自动测试通过；正式 Qt 按钮完成 24 个操作用例。GitHub 生成的便携包另经实机验证：实际 319.975Hz Dolby Vision、工具箱重启后返回原 4K 160Hz、恢复原 EDID。两种分辨率均保持 RGB 10 位。正式安装包已完成升级验收，原配置与 69 项原生参数保持一致。

实机范围、逐项耗时和限制见 [调节响应优化](https://github.com/FallmoonXD/Mimonitor_Toolbox_2025/blob/main/docs/2025-control-performance.md) 与 [杜比视界 PC 实测](https://github.com/FallmoonXD/Mimonitor_Toolbox_2025/blob/main/docs/2025-dolby-pc.md)。本次信号及原生参数回读验证不替代仪器测色。
