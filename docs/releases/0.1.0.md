# Mimonitor Toolbox 2025 v0.1.0

红米 G Pro 27U **2025 款**维护版的首个 Release，基于 YiHoooong/Mimonitor_Toolbox。

## 下载

- `MonitorToolbox2025-Setup.exe`：Windows 64 位安装版，默认安装到当前用户目录，适合日常使用。
- `MonitorToolbox2025-portable.zip`：解压后运行 `MonitorToolbox2025.exe`，无需安装 Python。
- `SHA256SUMS.txt`：安装包与便携包的 SHA256 校验值。

两种版本使用同一配置目录 `%LOCALAPPDATA%\.gpro_controller_2025`。便携版的设置也保存在这里。使用过本仓库本地构建的用户可以保留现有配置。

## 本版内容

- 按实际 SDR、HDR、Dolby Vision 信号读取和调节原生显示模式，修正 2025 固件的模式编号及 HDR 色调映射对应关系。
- Windows Dolby Vision 开关变化后刷新信号状态；HDR/SDR 精密控光联动可指定显示器，避免第二屏状态干扰。
- 增加色彩增强四档控制，纳入新预设和撤销快照；保留 RGB、CMS 与当前白平衡点的回读检查。
- 画面选项按亮度、色彩、清晰度、专业设置分组；Gamma 偏移使用单行九档下拉，保留等待状态及失败回退。
- 适配 2025 款帧率开关、暗区增强、HDMI 色彩动态范围和炫彩灯；清理本机不支持的 2026 款入口。
- 应用采用紫底 MI 图标，托盘采用透明底白色 MI 图标。此仓库是独立维护版本。

## 验证与已知限制

实机验证环境为 Windows 11、红米 G Pro 27U 2025、固件 `OS3.0.109.0.UFFMAMN`。499 项自动测试通过；显示模式、HDR 色调映射、Windows 杜比开关联动、色彩增强和系统额外画面选项已有原生回读验证。

- 护眼开关会重载白平衡，目前只显示状态；CMS 和当前 20 点白平衡点也保持只读。
- SDR 游戏模式下的平滑渐变写入不生效，该状态下仅显示读数。
- 部分 HDR tone 调用的 Provider 返回 `-1`，工具箱保留警告并独立核对原生读数。
- 完整预设的实机应用、设备重启后的全部参数持久性，以及 FreeSync/竞技模式的完整 EDID 联动仍待进一步验收。
- 原生回读验证不等同于光学测量；本版未重新进行仪器测色。
