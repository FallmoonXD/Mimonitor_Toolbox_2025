# 2025 款 OSD 对照

实机：红米 G Pro 27U 2025 / beekeeper / OS3.0.109.0.UFFMAMN。核对日期：2026-10-13。

## 可调选项

| OSD 项目 | 工具箱 | 使用条件 |
| --- | --- | --- |
| 图像模式、屏幕亮度、对比度、锐度、精密光控 | 保留 | 按实际信号提供显示模式 |
| 色彩空间 | 保留色域六档 | Dolby Vision 下禁用 |
| 色彩动态范围 | 新增自动、全范围、有限范围 | HDMI SDR 或 HDR；DP、Dolby 下禁用 |
| 暗区增强 | 新增关、低、中、高 | 游戏模式；写入保留 Gamma 的其他位 |
| 灰阶响应时间、准星、320Hz竞技模式、FreeSync | 保留 | 原有游戏与输入条件 |
| 帧率显示 | 改为关、开 | 使用 2025 OSD 的开关和显示服务 |
| 输入源 | HDMI 1、HDMI 2、DP | 删除不存在的 USB-C；Android 桌面通过遥控器主页进入 |
| 炫彩灯 | 灯光开关、屏幕同色、四种光效、12 种颜色 | 关灯时停用子选项；屏幕同色停用光效和颜色；颜色适用于常亮、呼吸 |

炫彩灯光效为常亮、呼吸、七彩梦境、七彩跑马灯。预设颜色与本机 OSD 保持一致。设置失败或回读不可用时不显示成功，不用默认值掩盖未知状态。

暗区增强和色彩动态范围可保存进新预设；旧预设没有记录时保持现状。色彩动态范围只在预设记录的同一 HDMI 输入上应用。

## 清理的入口

动态清晰度、动态准星、狙击镜、狙击镜夜视、三档 FPS 计数器、秒表、定时器属于该固件的 PM2 菜单分支，本机未启用。删除对应入口，旧预设中的动态清晰度不再写入。

2026 款的照明模式、灯光亮度、照明色温、五色面板及相应亮度快捷键已替换。2025 款使用独立的灯光开关、光效、预设颜色和屏幕同色协议。

菜单旋转、CEC、待机倒计时、HDMI/DP 模式等继续通过实机 OSD 操作。遥控器页增加“显示器 OSD”，直接打开该菜单。“菜单”按钮仍打开游戏快捷菜单。

## 护眼模式与校色

护眼模式保留当前状态显示，禁止工具箱写入。实机隔离测试确认，开启它会从自定义色温切到暖色，并把当前 RGB 增益重载为默认值；只关回开关不能恢复自定义 RGB。界面说明这一限制。

测试中恢复了当时 Dolby 模式的 RGB 和当前白平衡点的选择位置，未主动写 CMS 或 20 点白平衡表。后来发现 SDR、HDR 的校色参数没有完整恢复；2026-10-14 已按既有校色档案分别修复并重新核对，见 [系统画面设置](2025-system-picture-settings.md)。

## 验证范围

- 暗区增强四档在 Dolby 游戏、色彩动态范围三档在 HDMI SDR 游戏下实测：原生返回码及延迟回读通过，信号与模式稳定。
- 帧率开关：实际画面出现 `160`，关闭后恢复。
- 炫彩灯：开关、屏幕同色、四种光效、常亮模式下 12 种颜色的驱动回执及菜单值通过，结束后恢复原灯效。未进行背面灯光的光学测量。
- 色彩动态范围测试短暂关闭目标 `XMI27B3` 的 Windows HDR；测试后恢复 HDR 和 Dolby Vision 输出。
- 50 个校色相关原生字段、112 个画质数据库字段的恢复检查只覆盖当时的 Dolby 模式；另核对新增原生字段和灯光开关。

固件 APK 与运行配置也已重新读取。此轮核对限于显示器 OSD，完整系统画面选项已在 [系统画面设置](2025-system-picture-settings.md) 中另行核对，不据此声明其他机型的支持情况。

实机发现 HDMI FreeSync 的 native 值 `1` 表示开启，原工具箱只认 `3`，已修正页面、预设采集和快捷键查询的识别。菜单初始化会按 EDID 重设 FreeSync；本轮未另行验收 FreeSync/320Hz 的完整写入及 EDID 联动，因此不将它们计入上述逐档写入验收。
